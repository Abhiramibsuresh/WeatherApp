🌦️ WeatherApp

A simple and responsive Weather Application built using HTML, CSS, and JavaScript. It uses the OpenWeather API to fetch and display real-time weather information for different cities.

✨ Features

- 🔍 Search weather by city name
- 🌡️ Display current temperature
- 🌤️ Show weather conditions and icons
- 💧 Display humidity
- 💨 Display wind speed
- 🌡️ Show feels-like temperature and atmospheric pressure
- ⚠️ Handle invalid city names and API errors
- 📱 User-friendly interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API
- Fetch API
- Async/Await

📂 Project Structure

```text
WeatherApp/
```

**Note:** `config.js` contains your local API configuration and should not be uploaded to a public repository.
 🚀 Getting Started
 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```
 2. Open the Project

Open the project folder in VS Code.

3. Configure the API Key

Create a local `config.js` file using the structure shown in `config.example.js`. Add your own OpenWeather API key.

Keep your actual API key private.

 4. Run the Application

Open `weather.html` in your browser, or use the Live Server extension in VS Code.

🔑 API Used

This project uses the [OpenWeather API](https://openweathermap.org/api) to retrieve weather information.

You need your own API key to fetch weather data.
